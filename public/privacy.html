검색창에 입력한 내용

KNU Room AI의 Vercel 서버는 입력한 문장, 이전에 확정한 지역·예산·통학 조건과 지역 확인 답변을 받아 검색 조건을 해석합니다. 이름이 같은 동이나 구를 구분할 때는 국내 행정구역 목록을 대조합니다. 검색할 때는 동 이름이나 학교·역 이름 정도면 충분합니다. 이름, 전화번호, 개인의 상세 거주 주소는 입력하지 마세요.

외부 AI 분석을 사용하는 검색에서는 설정에 따라 OpenRouter와 해당 모델 제공자 또는 Google Gemini에 검색 문장을 전송해 조건을 추출합니다. 기본 파서로만 처리하는 단계에서는 서버가 자체적으로 해석합니다. 매물 공개 준비 상태에서도 입력 조건을 해석할 수 있습니다.

장소·지도·보행 경로

  • 목적지 찾기. 등록된 장소만으로 학교나 직장을 확인할 수 없는 경우, 장소 찾기를 실행하면 검색한 기관명이나 주소를 Photon에 보내 OpenStreetMap 장소 후보를 조회합니다.
  • 보행 경로. 공개 장소 간 경로를 요청하면 서버가 선택한 두 장소의 대표 좌표를 TMAP에 보냅니다. 매물 경로 기능을 사용할 때는 해당 매물의 좌표와 목적지 좌표를 보냅니다. 이 기능은 기기의 현재 위치를 요청하지 않습니다.
  • 지도 열기. 매물의 위치 지도를 열면 브라우저가 표시할 좌표와 지도 범위를 OpenStreetMap으로 보냅니다. 이때 지도 서비스가 브라우저의 IP 주소 등 웹 요청 정보를 받을 수 있습니다.
  • 매물 자료. 서버는 기존 Apify Dataset 또는 저장된 매물에서 가격, 출처, 위치 정보를 읽습니다. 운영자가 신규 수집을 실행하는 경우 매물 범위와 검색 조건을 이용합니다.

저장 기간과 삭제

  • 로그인. 입력한 키는 이 사이트의 서버가 확인합니다. 브라우저에는 매물 검색용 세션 쿠키를 저장합니다. 이 쿠키는 페이지 스크립트가 읽을 수 없으며, 로그인한 지 1시간이 지나면 만료됩니다. 공용 기기에서는 검색을 마친 뒤 ‘로그아웃’을 눌러 쿠키를 지우세요.
  • 브라우저. 검색 중인 조건과 확인 질문은 페이지 메모리에서 관리합니다. ‘조건 초기화’로 현재 화면의 검색을 비울 수 있습니다. 직접 선택한 밝은·다크 테마는 브라우저에 저장되며 이 사이트의 저장 데이터를 지우면 삭제됩니다.
  • 서버 캐시. Upstash Redis에 AI 조건 해석 성공 결과를 최대 10분 보관합니다. 장소 검색 결과는 최대 7일, 확인한 OpenStreetMap 장소는 최대 30일 저장합니다. 저장이 허용된 경우에만 TMAP 경로의 거리·시간 요약을 최대 23시간 보관합니다.
  • 이용량 보호. 기능별 호출 제한, 예산 예약, 중복 방지를 위해 Redis에 카운터와 잠금을 둡니다. 공개 요청은 접속 주소에서 계산한 해시값을 이용해 횟수를 구분할 수 있습니다. 도보 요청의 개인별 횟수 제한은 1분, 일일 집계 키의 만료 시간은 48시간입니다.
  • 매물 자료. 수집한 매물은 정해진 자동 만료 기한 없이 갱신·저장하며, 운영자가 만든 매물 백업에도 들어갈 수 있습니다. 화면의 검색 조건 초기화는 서버의 캐시·매물·외부 서비스 기록까지 삭제하는 기능을 제공하지 않습니다.

운영 검토와 문의 절차

이 안내는 현재 구현한 처리 방식을 기준으로 작성한 공개 전 초안입니다. 운영자 정보, 개인정보 열람·정정·삭제 요청을 받을 비공개 문의처, 외부 서비스별 처리 국가·보관 기간과 이전 조건은 정식 매물 공개 전에 확정해 게시해야 합니다. 공개 게시물에는 개인정보나 인증키를 남기지 마세요.
